# Frontend Study Projects

Este repositório reúne projetos desenvolvidos durante meus estudos de HTML e CSS. Os projetos foram criados com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end, incluindo estruturação de páginas, estilização, responsividade e animações.

## Projetos

* Formulário de Matrícula
* Portal de Notícias
* Patins Animation
* Travelgram
* Receita Cupcake de Café
* Zingen

 ## Utilizadas

* HTML5
* CSS3

## Objetivo

Consolidar conhecimentos em desenvolvimento web por meio da criação de projetos práticos e exercícios propostos durante os estudos.
