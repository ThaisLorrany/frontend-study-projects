# Tech News - Portal de Notícias

## 📖 Sobre o Projeto

Tech News é um portal de notícias desenvolvido com HTML e CSS, focado na divulgação de conteúdos relacionados à tecnologia e inovação.

O projeto apresenta uma interface moderna inspirada em grandes portais de notícias, destacando matérias sobre Inteligência Artificial, Blockchain, Hologramas, Internet, Realidade Virtual, Realidade Aumentada e outras tendências tecnológicas. O layout foi construído para oferecer uma navegação organizada e agradável, priorizando a leitura e a apresentação visual das notícias.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3

## ✨ Funcionalidades

* Página inicial com notícias em destaque
* Seções organizadas por categorias
* Cards de notícias com imagens e descrições
* Design moderno inspirado em portais de tecnologia
* Estrutura desenvolvida sem JavaScript

## 🎯 Objetivo do Projeto

Este projeto foi criado com o objetivo de praticar conceitos de desenvolvimento front-end, incluindo:

* Estruturação semântica com HTML
* Criação de layouts utilizando CSS Grid
* Posicionamento e alinhamento de elementos
* Responsividade para diferentes dispositivos
* Organização visual de conteúdos
* Aplicação de boas práticas de design web

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram explorados conceitos importantes de HTML e CSS, como a utilização de grids para construção de layouts complexos, estilização de componentes, organização de seções de conteúdo e criação de interfaces modernas para portais de notícias.

## 📌 Status do Projeto

Projeto concluído para fins de estudo e prática de HTML e CSS.
