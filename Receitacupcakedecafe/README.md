# Receita de Cupcake

## 📖 Sobre o Projeto

Este projeto consiste em uma página web simples de receita de cupcake, desenvolvida utilizando HTML e CSS. O objetivo é apresentar de forma clara e organizada os ingredientes, modo de preparo e informações da receita em uma interface agradável e intuitiva.

A página foi criada com foco na prática de estruturação de conteúdo e estilização utilizando apenas tecnologias básicas do desenvolvimento front-end.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3

## ✨ Funcionalidades

* Exibição da receita completa
* Lista de ingredientes organizada
* Passo a passo do modo de preparo
* Layout limpo e agradável
* Design responsivo para diferentes dispositivos

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para praticar conceitos fundamentais de HTML e CSS, incluindo:

* Estruturação semântica de páginas web
* Organização de conteúdo textual
* Estilização de elementos com CSS
* Uso de imagens e tipografia
* Construção de layouts simples e responsivos

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram aplicados conceitos essenciais de front-end, como formatação de textos, espaçamento entre elementos, utilização de cores, imagens e criação de uma interface visualmente agradável para o usuário.

## 📌 Status do Projeto

Projeto concluído para fins de estudo e prática de HTML e CSS.
