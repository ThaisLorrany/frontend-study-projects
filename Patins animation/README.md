# Patins Animados

## 📖 Sobre o Projeto

Patins Animados é uma landing page desenvolvida com HTML e CSS, criada com o objetivo de praticar a construção de interfaces modernas e interativas para a web.

O projeto apresenta uma página temática sobre patins, utilizando animações, transições e efeitos visuais para proporcionar uma experiência mais dinâmica ao usuário. Além disso, conta com imagens distribuídas ao longo do layout, destacando conceitos de design responsivo e organização visual.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3

## ✨ Funcionalidades

* Layout moderno e responsivo
* Animações com CSS
* Efeitos de transição em elementos da página
* Galeria de imagens integrada ao design
* Estrutura organizada e sem utilização de JavaScript

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para praticar conceitos fundamentais e avançados de HTML e CSS, incluindo:

* Estruturação semântica de páginas web
* Uso de animações com `@keyframes`
* Aplicação de `transform` e `transition`
* Posicionamento e alinhamento de elementos
* Organização e estilização de layouts modernos

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram explorados conceitos importantes de front-end, como criação de animações suaves, manipulação visual de elementos com CSS e construção de interfaces mais atrativas sem o uso de JavaScript.

## 📌 Status do Projeto

Projeto concluído para fins de estudo e prática de HTML e CSS.
