# Zingen

## 📖 Sobre o Projeto

Zingen é uma landing page moderna desenvolvida com HTML e CSS para promover um aplicativo de karaokê. O projeto apresenta uma interface elegante, animações visuais e um design responsivo, proporcionando uma experiência agradável em diferentes dispositivos.

A página destaca os principais recursos do aplicativo, planos disponíveis e chamadas para ação, incentivando os usuários a conhecerem e baixarem o app.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3

## ✨ Funcionalidades

* Landing page moderna e intuitiva
* Design totalmente responsivo
* Efeitos visuais com CSS
* Seções informativas sobre o aplicativo
* Destaque para funcionalidades e planos
* Botões de chamada para ação (CTA)

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para praticar conceitos de desenvolvimento front-end, com foco em:

* Estruturação semântica utilizando HTML
* Criação de layouts modernos com CSS
* Responsividade para diferentes tamanhos de tela
* Utilização de animações e transições
* Organização visual de componentes
* Boas práticas de design para landing pages

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram explorados conceitos importantes como responsividade, posicionamento de elementos, animações com CSS, uso de gradientes, adaptação para dispositivos móveis e construção de interfaces modernas voltadas para a divulgação de produtos digitais.

## 📌 Status do Projeto

Projeto concluído para fins de estudo e prática de HTML e CSS.
