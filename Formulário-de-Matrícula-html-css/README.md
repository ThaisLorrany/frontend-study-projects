# Formulário de Matrícula Infantil

## Sobre o Projeto

Este projeto consiste em um formulário de matrícula para crianças em atividades esportivas e recreativas, desenvolvido durante uma aula da Rocketseat.

O formulário permite o preenchimento de informações necessárias para a inscrição da criança em atividades como vôlei, futebol, natação, entre outras. O foco do projeto é a construção da interface utilizando apenas HTML e CSS, aplicando conceitos de estruturação de formulários, organização de campos e estilização responsiva.

## Tecnologias Utilizadas

* HTML5
* CSS3

## Funcionalidades

* Cadastro de informações da criança
* Seleção de atividades esportivas
* Campos para dados 
* Layout organizado
* Interface moderna e intuitiva

## Objetivo

Praticar conceitos fundamentais de desenvolvimento web, especialmente a criação e estilização de formulários utilizando apenas HTML e CSS.
